# Vendor Access Closeout Register

Use one row per logical or physical access instrument. Do not record passwords, gate codes, or unnecessary personal data.

## Admission

- Stable facility ID and verified individual subject ID
- Vendor organization and governing work record
- Instrument type and nonsecret instrument ID
- Approved resource scope and purpose
- Authorization owner and issuing actor
- Start, expected end, and maximum expiration

## Departure and termination

- Work state and work-state evidence
- Departure state, time, and evidence
- Termination action: disable, expire, recover, or rotate
- Command/return actor, time, and source record
- Authoritative inactive or custody readback

## Exception and decision

- Final access state: disabled, expired, recovered, rotated, lost/unrecovered, or unknown
- Exception owner and next review time when not verified
- Approved contingency or escalation reference
- Reviewer, review time, and closeout decision
- Limitations preserved; no unsupported security conclusion

Close only when every issued instrument has a verified end state or an explicitly owned exception.
