# Vendor Work Order Disclosure Worksheet

Use one worksheet per work type, facility and recipient role. Enter internal record references in the controlled approval system.

## Define what the recipient needs

| Field or object | Proposed treatment for a common-area inspection |
| --- | --- |
| Facility and work location | Include verified address, affected area and staff meeting point. |
| Service scope | Include approved task and distinguish staff observation, customer report and open diagnosis. |
| Callback | Prefer the verified facility number. Route any customer callback request for a separate decision. |
| Credentials | Exclude from the packet. Handle access separately under the site procedure. |
| Tenant details | Exclude unrelated identity, account, unit contents and internal notes. |
| Evidence | Approve each specific derivative, name and version. Keep source provenance in the internal record. |
| Links | Test with the vendor role. Check the approved record, restrictions and available expiry and revocation settings. |

## Record the release decision

| Record | Complete at review |
| --- | --- |
| Purpose | Work type, facility, assignment and recipient role |
| Destination | Verified vendor, endpoint, channel and verification time |
| Materials reviewed | Subject, body, approved field set, attachments and recipient link view |
| Authority | Policy version, reviewer identity and scope, packet version and approval time |
| Delivery | Submission reference, provider acceptance, receipt status and open exceptions |

## Check the packet before delivery

- [ ] The draft contains only information allowed for this facility, job and recipient.
- [ ] Each attachment, filename and link target was reviewed from the vendor’s view.
- [ ] Recipient or payload changes invalidate the previous approval.
- [ ] A held packet shows an owner, a next action and any authorized alternate dispatch path.

## Worked example — explicitly fictional

| Larch Ferry Storage | Decision |
| --- | --- |
| Requested task | Inspect reported water near the second-floor loading corridor and report findings. |
| Share | Facility and corridor location, staff-observed damp patch, front-desk callback and staff meeting point. |
| Keep internal | Wide photo with customer label, customer mobile number, contents note and internal case link. |
| Scope change | If the work expands to a customer unit, open separate coordination and approval before releasing further details. |
