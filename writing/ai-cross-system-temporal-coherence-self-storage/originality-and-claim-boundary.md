## Tool boundary

The AI Temporal Coherence and As-Of Integrity Test is an architecture and operations diagnostic. Teams must set authorized fact ownership, time semantics, freshness limits, evidence and escalation rules for their systems and uses. The tool does not query systems, correct records, create a distributed transaction, certify clock synchronization or authorize an operational action.

## Source boundary

RFC 3339 informs timestamp representation, not business-time meaning. PROV-O informs provenance and temporal bounds, not a facility state model. CloudEvents informs event envelopes, not cross-system coherence. PostgreSQL documentation describes one database product, not a portfolio-wide snapshot. NIST AI RMF provides voluntary risk-management context, not this implementation or a compliance result.
