# Facility Checklist Version and Coverage Register

Use one row per facility, checklist family, and release episode. Add separate rows when a facility has multiple distribution surfaces or distinct applicability decisions that need independent evidence.

## Release gate

Before release, record the checklist family, version, approving owner, effective time, change class, exact differences, scope, required evidence, pass rule, critical-fail rule, superseded version, and distribution surfaces.

## Facility adoption gate

For each facility, verify:

1. the facility is in scope;
2. applicable modules match the current asset and area record;
3. the operator can reach the correct version from the normal work path;
4. obsolete versions are withdrawn or visibly retired;
5. the first required execution cites the released version; and
6. any exception has an owner, expiration, compensating step, and reconciliation plan.

## Portfolio comparison gate

Before aggregating results, confirm the executed version, applicable-item denominator, evaluation state, crosswalk eligibility, held records, and exclusions. Do not convert not-applicable, skipped, unanswered, or not-collected items into the same state.
