# AI Translation Meaning-Preservation Gate

Use one record per target-language artifact. A fluent output is not a release decision.

## 1. Message contract

- Stable message object ID, facility ID, purpose, audience, and consequence class
- Governing source record and approved source-text version/hash
- Facility/service subject, state, scope, start/end, and time zone
- Customer action, support route, uncertainty state, obligation class, and prohibited claims

## 2. Translation identity

- Source and target language tags
- Translation process, model/provider/human identifier
- Prompt, glossary, terminology, and locale-rule versions
- Target artifact ID, text hash, encoding, and channel set

## 3. Meaning invariants

- Facility and service subjects preserved
- Numbers, units, amounts, dates, times, and time zones preserved or approved-transformed
- Negation, uncertainty, estimate/commitment, condition, and obligation preserved
- No new cause, diagnosis, outcome, restoration, or authority claim
- Support route, hours, privacy, and disclosure boundaries preserved

## 4. Review and release

- Automated check results and unresolved differences
- Qualified language review required/completed
- Operating-authority review required/completed
- Release decision, approver, effective time, expiration, and authorized channels
- Failed or unknown results stop release and receive an owner

## 5. Correction lifecycle

- Source correction or supersession trigger
- Every dependent language/channel enumerated
- Stale hold, regeneration, rereview, correction release, and readback states
- What recipients actually received remains preserved

Release only when the target artifact is bound to the approved source contract and all required meaning, review, channel, and correction controls pass.
