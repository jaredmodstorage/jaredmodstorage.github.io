# Move-Out Reason Coverage Worksheet

Use one row per eligible case in an approved system. Roll up by facility, move-out route and question version once the shared response window closes.

## Define the cohort and the evidence

| Check | Record |
| --- | --- |
| Population | Lease endings or distinct customers, reporting dates and inclusion rules |
| Case key | Facility ID, case ID, effective departure date and move-out route |
| Invitation | Unique invite status, disposition and contact history |
| Answer | Reason-question completion, primary choice, customer or staff provenance and question version |
| Time | Shared response window, as-of date and late-response rule |
| Review | Case counts by facility and route, unavailable evidence and reason for any exclusion |

## Calculate the three measures

| Measure | Calculation |
| --- | --- |
| Invitation coverage | Unique invitations sent ÷ eligible cases |
| Answer coverage | Usable reason answers ÷ eligible cases |
| Share for one reason | Selections of that reason ÷ usable answers, using one primary response per case |
| Zero base | If the denominator is zero, display unavailable and preserve counts. |

## Release the comparison

- [ ] Reconcile statuses to the eligible list using mutually exclusive final outcomes.
- [ ] Check that questions, options, evidence source and response windows align.
- [ ] Compare coverage by route and show counts next to each reported share.
- [ ] Label the row investigation only, respondent comparison or population estimate based on its evidence. Name an owner for each material gap.

## Worked example — explicitly fictional

| Site | Eligible / invited / answered / price |
| --- | --- |
| Juniper Slip | 100 / 80 / 50 / 20. Price is 40% among usable answers. |
| Slate Landing | 100 / 40 / 20 / 10. Price is 50% among usable answers. |
| Remote answer coverage | Juniper Slip 15 of 50. Slate Landing 2 of 50. |
| Disposition | Investigation only for a portfolio ranking. Keep the respondent shares visible and assign the low remote coverage to the workflow owner. |
