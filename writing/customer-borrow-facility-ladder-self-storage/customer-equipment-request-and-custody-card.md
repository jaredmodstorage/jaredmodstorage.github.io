# Customer Equipment Request and Custody Card

Use this card whenever a customer, vendor or other non-employee asks to borrow facility-owned portable equipment. Complete the policy gate before touching or moving the requested asset. A pending answer does not authorize release.

## 1. Request identity

- Request ID
- Request date and time
- Facility ID
- Requester role
- Requester name or customer reference, following the approved privacy rule
- Customer unit or work-area reference
- Requested task
- Proposed task location

## 2. Policy boundary

- Current policy reference and version
- Requested user class explicitly allowed: yes / no / unknown
- Asset classified staff-use-only: yes / no / unknown
- Decision authority
- Supervisor review required: yes / no
- Supervisor review state: approved / declined / pending / not required

If the user class is not expressly allowed, record **not released**. If policy or authority is unknown, record **pending review** and retain facility custody.

## 3. Exact asset

- Asset ID
- Asset type
- Manufacturer label present and readable: yes / no / unknown
- Rated capacity visible: yes / no / unknown
- Designed-use match: pass / fail / unknown
- Last inspection date and time
- Inspector or record reference
- Current condition: pass / fail / unknown
- Defect, tag-out or quarantine reference

Do not release an unidentified asset, an asset with an open defect, or an asset whose required condition state is unknown.

## 4. Work environment

- Surface condition: acceptable / unacceptable / unknown
- Doorway, drive-lane or traffic exposure: yes / no / unknown
- Energized or overhead hazard present: yes / no / unknown
- Other displacement or access hazard
- Task or location changed after review: yes / no

A changed task or location requires a new review. Do not stretch the original approval to fit new conditions.

## 5. Decision and communication

- Decision: released / not released / pending review
- Decision reason
- Approved alternative, if any
- Exact customer message
- Decision owner
- Decision time

## 6. Custody and closeout

- Named asset custodian
- Released at
- Due back at
- Returned at
- Return condition: pass / fail / unknown / not released
- Quarantine or follow-up reference
- Follow-up owner
- Follow-up due
- Evidence reference
- Material limitations or unresolved facts
- Closed by and closed at

## Decision language

- **Released:** Every required gate passed and the authorized decision owner approved release.
- **Not released:** At least one required gate failed.
- **Pending review:** Information or authority is missing; the asset stays in facility custody.

The completed card documents the decision process. It is not proof that a task was safe, that a customer was qualified or that no incident occurred.
