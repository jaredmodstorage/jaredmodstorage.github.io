# Chemical Eye Exposure First-Response Card

Use this card after a chemical reaches or may have reached an employee's eye. It organizes the shift response; it does not diagnose an injury, replace the product label or SDS, or replace 911, Poison Control or medical direction.

|---|---|
| Exposure time / discovered time |  |
| Eye(s) involved | right / left / both / unknown |
| Irrigation start time |  |
| Water source |  |
| Contact lens status | none / removed while rinsing / remained / unknown |
| Symptoms directly observed or reported |  |
| 911 called / time / instruction |  |
| Poison Control or medical contact / time / instruction |  |
| Irrigation end time and who directed it |  |
| Medical handoff destination / time |  |

**Immediate order:** begin irrigation with clean water, bring help to the person and follow emergency direction. General Poison Control guidance describes 15 to 20 minutes of rinsing; the exact product label, SDS and medical direction govern the case. Do not delay flushing to find paperwork.

## 2. Identify in parallel: product owner

| Record | Entry |
|---|---|

Do not guess from bottle color, odor or storage location. If the label and SDS do not match exactly, record `unconfirmed` and say so to the medical resource.

| Record | Entry |
|---|---|
| Release location and boundary |  |
| Customers / employees redirected |  |
| Other possible exposures |  |
| Container state | upright / leaking / unknown / moved only if safe |
| Cleanup owner and escalation |  |

Do not neutralize, mix, drain or clean an unknown or out-of-scope release. Keep the area closed until the trained and authorized owner completes the required response.

Use factual wording such as `employee reported burning in right eye`. Do not write `minor`, `no injury` or `resolved` unless the qualified owner has made and documented that determination.
